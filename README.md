# Lupton Associates — Brand Videos

LinkedIn brand videos for Lupton Associates, plus the reusable production
system used to make them.

**If you are an AI agent asked to produce a Lupton video: read `CLAUDE.md`
first.** Despite the filename, it is tool-agnostic — it is the complete
production playbook (brand system, editorial pattern, ffmpeg recipes, voice
cloning, verified copy rules, QC loop). Every reusable asset it references
lives in `brand-kit/`:

- `brand-kit/badge.png` — LA badge (white mark on sage)
- `brand-kit/fonts/` — Inter, Oswald, Archivo Black
- `brand-kit/templates/` — HTML overlay templates (cards, statements,
  end card, staggered-text layers, paint-swipe transition slabs)
- `brand-kit/audio/` — narrator reference for voice cloning, recorded
  narration lines T1–T8, whoosh SFX
- `brand-kit/music/` — score (Kevin MacLeod, incompetech.com, CC BY 4.0 —
  published posts must credit "Music: Kevin MacLeod (incompetech.com),
  CC BY 4.0")
- `brand-kit/clips/` + `brand-kit/frames/` — source footage and keyframes

Current shipped video: `lupton-buyer-painting-v7.mp4` (viewer:
`painting.html`). Legacy reference: `lupton-manufacturing-v9.mp4`
(`index.html`) — do not modify.
